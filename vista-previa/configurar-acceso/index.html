Salta Emplea · Configuración privada

Prepará el acceso al panel

Esta herramienta funciona dentro de este archivo. No envía tu contraseña ni las claves a ningún servidor y no las guarda.

Elegí una contraseña exclusiva de al menos 12 caracteres. Guardala en tu gestor de contraseñas: será la que uses para entrar al panel.

Usá una frase larga y única. La contraseña no aparecerá entre los resultados.

Copiá estos tres valores a Vercel

Abrí las variables de entorno de Salta Emplea. Para cada nombre, pegá su valor, elegí Production y guardalo como Secret / Sensitive.

No pegues estos valores en el chat, en GitHub ni en un documento compartido. Cada botón selecciona el valor: copiá con Ctrl+C o con la opción Copiar de tu celular.

Las claves aparecen únicamente en esta pestaña. Al cerrarla se pierde esta configuración local. Si generás otra, los tres valores cambiarán: no reemplaces claves de una app activa sin coordinarlo antes.
