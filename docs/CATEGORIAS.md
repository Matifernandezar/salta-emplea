# Categorías de Salta Emplea

Catálogo único para carga, filtros, alertas y sugerencias de Claude:

- Administración / Oficina
- Almacén / Logística / Transporte
- Atención a clientes
- CallCenter / Telemercadeo
- Compras / Comercio Exterior
- Construcción y obra
- Contabilidad / Finanzas
- Dirección / Gerencia
- Diseño / Artes gráficas
- Docencia
- Hostelería / Turismo
- Informática / Telecomunicaciones
- Ingeniería
- Investigación y Calidad
- Legal / Asesoría
- Mantenimiento y Reparaciones Técnicas
- Medicina / Salud
- Mercadotecnia / Publicidad / Comunicación
- Otros
- Producción / Operarios / Manufactura
- Recursos Humanos
- Servicios Generales, Aseo y Seguridad
- Ventas

Los nombres y el orden siguen las capturas proporcionadas por el titular. El campo interno se conserva como `sector`, sin cambiar el esquema de base de datos.

Los rubros históricos se muestran mediante equivalencias explícitas; los desconocidos se agrupan en Otros. El dato original de base y su procedencia se conservan. Los filtros antiguos con equivalencia siguen funcionando. Una categoría vacía significa pendiente de clasificación, no una categoría adicional.

Claude recibe la lista cerrada y solo puede proponer una categoría respaldada por el puesto o sus tareas en la transcripción. La sugerencia editorial queda señalada para revisión; no altera la aprobación ni publica automáticamente. Las pruebas sustituyen el proveedor y no demuestran la precisión de una clasificación real.
